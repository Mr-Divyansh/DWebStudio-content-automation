# Instagram Post Generation Prompt

## Purpose

Generate an Instagram post from an approved client content brief.

## Required Inputs

- business/brand name;
- promotion or subject;
- content goal;
- target audience;
- client-provided facts;
- CTA;
- contact/social information when provided;
- requested tone.

## Output

Return:

1. Hook
2. Main caption
3. CTA
4. Hashtag suggestions
5. Review notes

## Rules

- Use only supplied client facts.
- Do not invent prices, dates, claims, URLs, phone numbers, testimonials, or guarantees.
- If a necessary fact is missing, identify it instead of guessing.
- Keep the output suitable for Instagram.
- Maintain the requested tone.
- Write clear, marketing-focused language for the intended audience.
