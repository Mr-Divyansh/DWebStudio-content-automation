# WhatsApp Export Folder

Place exported WhatsApp `.txt` or `.zip` chat files in this directory.

Supported format:
Standard WhatsApp exported chat text format, e.g.:
`[24/02/2025, 14:32:10] Client Name: Hi, we saw your portfolio on Instagram.`
`[24/02/2025, 14:33:05] D Web Studio: Hey there! Thanks for reaching out. What kind of project are you planning?`

You can also paste or upload WhatsApp conversations directly in the web UI!
