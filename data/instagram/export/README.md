# Instagram Export Folder

Drop your downloaded Instagram data export ZIP file here (e.g. `instagram-export.zip` or `your_username_20250101.zip`).

The D Web Studio Lead AI importer will automatically:
1. Detect any `.zip` files placed in this folder.
2. Safely extract files and discover JSON message files (e.g. `messages/inbox/.../message_1.json`).
3. Handle UTF-8 encoding variations from Instagram.
4. Normalize conversations, extract leads, and feed them into the AI analyzer.

You can also upload ZIP files directly via the Web Dashboard "Imports" screen!
